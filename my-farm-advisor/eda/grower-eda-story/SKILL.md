# Grower EDA Story

Use this subskill for reusable field-level exploratory analysis across runtime
field boundaries, USDA CDL/cropland summaries, and NASA POWER weather. The
current Assignment 2 comparison is one example use case. It is routed under
the My Farm Advisor EDA skill and produces static CSV, JSON, and PNG artifacts
only. Read `README.md` for the runtime contract and artifact definitions; use
the routed EDA helper guides for comparison, time-series, and visualization
methods. A one-time report may consume these artifacts but is not generated by
this subskill.
