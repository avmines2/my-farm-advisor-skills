# Provenance

- Field boundaries: USDA Cropland Data Layer field boundaries supplied by the
  runtime pipeline through the canonical farm GeoJSON files.
- Cropland history: USDA Cropland Data Layer yearly field composition tables,
  2019–2023, already generated by the runtime pipeline.
- Weather: NASA POWER daily weather tables generated by the runtime pipeline,
  sampled at field centroids, 2021–2025.
- Calculations: pandas, GeoPandas, NumPy, and the Python standard library.
- This subskill creates derived tables and manifests only. It does not copy or
  commit runtime data bundles.
